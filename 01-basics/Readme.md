## What I learned

- Creating new file in project with command -
  `dotnet new console -n FileName`

- Adding to existing solution -
  `dotnet sln CSharpLab.sln add relative/path/file.csproj`

- Run project - `dotnet run --project relative/path`

## Data Types

- int
- float
- string
- const

## OOP

- Main() Method with return type for execution, required for program execution
- void : Method does not return
- string[] args : Command line arguments can be accessed
